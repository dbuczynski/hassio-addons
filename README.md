# Home Assistant Addons & Custom Integrations

Welcome to my Home Assistant repository.

## Components

- **[Galeria Twarzy](galeria_twarzy/)**: A custom integration for Home Assistant to scrape and track castings from `galeriatwarzy.pl`.
- **[Web server andrzejow.net](addons/andrzejow.net/)**: Home Assistant Add-on with Coin Label Generator, YouTube Wheel of Fortune, and Activity Logging.

## Installation

Add this repository to your Home Assistant Supervisor or HACS to access the components.
